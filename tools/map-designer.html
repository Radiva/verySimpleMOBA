Alat Desain Peta — Garis Depan

Klik di area kanvas kosong untuk menambah titik baru di ujung jalur. Seret sebuah titik untuk memindahkannya. Klik kanan pada titik, atau pilih lalu tekan Delete, untuk menghapusnya (minimal 2 titik). Titik pertama = ujung sisi pemain (kiri), titik terakhir = ujung sisi musuh (kanan) — urutan di antaranya menentukan kelokan jalur. Referensi abu-abu (nexus, menara, zona aman, kemp hutan) dibaca langsung dari data/mapshape.js supaya kamu bisa menyelaraskan jalur dengannya; alat ini sendiri tidak mengubah file-file itu.
